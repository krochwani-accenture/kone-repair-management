Kone Repair Management — How Data Flows

What happens behind the scenes when you click each button

① Click "Upload"
User clicks Upload button
A pop-up dialog opens asking you to choose a file
User picks an Excel file (.xlsx) from their computer
Selected file name is shown inside the pop-up
Next step ↓
User clicks Save inside the pop-up
Pop-up closes. File is handed to the app and a Load bar appears at the top
② Click "Load"
User clicks Load in the file bar
App reads the Excel file and converts every row into data it can understand
All rows are loaded into the browser's memory
(nothing is saved yet)
✅ "File loaded successfully. Preview is ready." message shown for 5 seconds
Table is now filled with the uploaded rows & Save to Database button appears
③ Click "Save to Database"
User clicks Save to Database
All rows from the table are packaged and sent to the server
Server checks each row:
🆕 New row → Insert
🔄 Changed row → Update
✓ Same row → Skip
Server saves everything into the Database permanently
✅ Success message shown:
"Inserted: X, Updated: Y, Skipped: Z"
